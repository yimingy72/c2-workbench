# 控制台视觉基线

本文件记录 2026-09-09 工作台布局与配色。操作形态对照 Vshell（Vben Admin：顶栏、表格、命令控制），实现使用 React + Ant Design 6，不复制 Vshell 资源、协议或插件。用户已确认使用上导航，不再使用左侧导航轨道。

## 结构

桌面采用 48 px 顶部导航 + 内容区（对照 Vben `vben-layout-header`）。顶部从左到右：品牌标识、产品名称、监听管理 / 主机管理 / 载荷生成、监听与在线计数、配色、当前用户、退出。当前页用底边强调色标识。

内容区不再使用空三栏队列。各页为：

- 监听管理：页头 + 数据表格 + 新增弹窗。
- 主机管理：表格列出上线主机；进入后打开主机工作台（对照 Vshell `ClientManagerTab`）。工作台为 40 px 顶条（返回 / 主机名 / 状态）+ 铺满剩余高度的内容 + 40 px 底栏标签（命令控制 / 文件管理 / 屏幕截取 / 远程桌面）。内容区全宽，不再使用左侧功能栏。命令控制为铺满的 xterm（`#2A2C34`），不是单次 `cmd /c`。视觉仍用同一套配色。
- 载荷生成：说明条 + 参数表单 / 编译环境卡片 + 本次生成记录表。

720 px 以下隐藏产品名，导航仅保留图标；900 px 以下隐藏计数和用户名。长输出在终端容器内滚动，禁止撑宽页面。

## 色彩与组件

内置五套主题，默认雾银（对齐 Vben 浅色：画布 `#f4f7f9`，主色 `#0065cc`）。亮石墨对齐 Vben 深色画布 `#2c344a`。

| 配色 | URL 参数 | 内容与强调 | 使用算法 |
| --- | --- | --- | --- |
| 雾银（默认） | `theme=silver` | 浅灰画布、白卡片、Vben 蓝强调 | defaultAlgorithm |
| 冰蓝 | `theme=glacier` | 冰蓝画布、白卡片、深蓝强调 | defaultAlgorithm |
| 青瓷 | `theme=celadon` | 浅青画布、白卡片、青绿强调 | defaultAlgorithm |
| 亮石墨 | `theme=slate` | Vben 蓝灰内容面、浅青强调 | darkAlgorithm |
| 原石墨 | `theme=graphite` | 更深的对照暗色 | darkAlgorithm |

命令输出区始终使用深色终端底，不随浅色主题变成白底。CSS Modules 负责页面骨架；表格、表单、弹窗、标签使用 Ant Design 公开 API，不覆盖内部类名。

页头配色选择器只切换外观。URL 参数优先，其次 localStorage，再回退雾银。切换主题不触发业务命令。

## 字体

界面拉丁字形使用本地打包的 Inter Variable，中文使用 PingFang SC / Microsoft YaHei。地址、编号、终端使用 IBM Plex Mono。不依赖外部 CDN。

页标题 18 px，登录主标题 22–28 px，正文与控件 13 px，表格与终端 12 px。

## 文案与行为

页面保留监听、主机、载荷、状态、命令输出和可执行动作。删除功能口号。登录页左侧仅产品名与「授权环境控制台」。

保留键盘跳转入口、可见焦点。状态不只依赖颜色。系统减少动态效果时禁用过渡。

## 凭据页（2026-10 追加）

主机工作台底栏标签由 4 个扩展为 5 个：命令控制 / 文件管理 / 屏幕截取 / 远程桌面 / 凭据。凭据是独立标签而不是浏览器标签的子面板，因为它同时承载浏览器与系统两侧的采集结果。

页面结构沿用浏览器信息页的密度：

- 40 px 动作条：深度收集 / 系统凭据 / 全部收集 / 刷新 / 导出 CSV / 删除。扫描类按钮在主机离线时禁用，运行中显示 `loading`，同一时刻只允许一个采集任务。
- 采集元信息行：主机名 + 采集时间 + 总条数，12 px 等宽字体。
- 6 张统计卡：总数 / 浏览器 / 系统 / WiFi / 凭据管理器 / 密钥。数字 20 px，标签 12 px，卡片底色用 `--wb-panel`。
- 筛选行：搜索框（来源 / 目标 / 用户 / 备注）、来源下拉、类型下拉、右侧「全部显示」与 `n / m 条` 计数。
- 表格 8 列：类型 / 来源 / 目标 / 用户 / 密钥 / 备注 / 采集时间 / 操作。类型列使用 `Tag`，颜色按类型固定；目标列在像 URL 或路径时切换等宽字体。
- 密钥列默认只显示脱敏预览（前 2 + 后 2），眼切换按条调用 `POST /api/creds/{host}/reveal` 取明文，明文只存在组件内存里，不写回列表接口。按钮带 `aria-pressed`，键盘可达。
- 空态与离线态用文字说明，不只靠颜色区分；错误通过 `message.error` 呈现服务端原文。

浏览器信息页新增两块：文件行的操作列按库类型给出「浏览历史 / 下载记录 / 自动填充 / 账号列表 / Cookie 元数据 / 表单历史」，以及「配置摘要」表（来源 `K` 加密方案、`P` 配置身份）。头部计数改为 `文件 · 书签 · 扩展 · 配置`。
